# 墨迹：隐私、权限与数据保存

适用版本：v1.10。

## 普通标注

扩展在你允许访问的网页上运行内容脚本，读取主文档文本与 DOM，以创建、展示和恢复标注。普通标注不依赖墨迹账户或远端服务器，也不包含分析统计或广告 SDK。

本地保存来源网址和标题、摘录及上下文、样式、颜色、标签、笔记、历史版本、回收站、草稿、配色及已取得的双语定位证据。数据位于扩展自己的 Chrome 本地存储中。

保存后读回校验，更新笔记时检查版本；冲突输入保留为草稿。删除进入回收站，恢复历史生成新版本。本地存储不能抵御卸载扩展、删除浏览器配置、磁盘损坏或系统重装。

## 可选的 Codex 连接

连接器只监听 `127.0.0.1`，默认端口 `38475`。扩展通过本机 WebSocket 连接，使用本机生成的随机令牌认证。连接器核对扩展来源与令牌，不提供任意 JavaScript 执行接口。

Codex 可列出已打开网页的标题和网址，并读取目标页面正文。连接器在内存中保留有容量限制的文章快照，供章节分页与编号标注使用；写入前核对正文版本，变化后拒绝旧快照。

原始正文在本机扩展与连接器之间传输，模型收到工具返回的目录、正文片段与结果。**Codex 会使用这些内容进行 AI 分析，因此启用连接不表示论文始终停留在本机或模型离线运行。** Codex 的数据处理、账号和额度由你使用的环境决定。请只让它读取你愿意交给该环境处理的内容。

`.moji/connection.json` 含本机连接令牌，默认被 Git 忽略。不要上传或分享。连接配置不包含在笔记备份和公开安装包中。

## 侧栏任务与独立阅读会话

用户在侧栏点击“开始”后，连接器会启动本机已登录的 Codex CLI App Server，创建临时独立阅读会话。不带入墨迹开发聊天；会话停用无关 MCP、技能与应用，只向三个阅读工具绑定当前页面，使用只读工作环境。你的 Codex 模型、登录、使用额度及服务端数据处理规则仍然适用。

快捷任务只填入输入框，不会自动发起。页面脚本合成的开始、停止或撤销点击不会触发任务。任务工具不提供任意系统命令、文件编辑或其他页面的访问入口。

连接器在 `.moji/reading-tasks.json` 明文保存任务描述、来源网址、简短结果、数量、用量统计（如返回）和任务/批次编号，用于找回最近任务及撤销。文章完整快照只在本次连接器内存中缓存，不写入该任务历史。任务记录目录默认不提交到 Git，也不包含在发布包中；迁移连接器时如需保留任务列表，应自行妥善保管，勿公开分享。

停止中断生成并阻止该任务后续写入，已提交内容保留。整批撤销按任务编号覆盖该任务的所有批次；最新笔记与双语证据进入回收站，不影响其他任务或手动标注。连接器重启会将未完成任务标记为停止，不自动重跑。

扩展更新导致旧脚本失效时，面板会保留未保存的输入，并允许下载明文 JSON 副本。点击刷新若仍有输入也会发起副本下载；请确认下载成功后再离开。副本不会自动导入、上传或替代正式标注备份。

## 扩展权限

| 范围 | 用途 |
| --- | --- |
| `storage` | 保存标注、笔记、设置及连接配置 |
| `unlimitedStorage` | 支持较多标注和保留的历史记录 |
| `alarms` | 定期尝试重连本机连接器 |
| HTTP / HTTPS 内容脚本 | 读取正文与选区，绘制标记、恢复位置 |
| 本地文件内容脚本 | 用户允许文件网址访问后标注本地 HTML |
| `http://127.0.0.1/*` 与本机 WebSocket | 连接可选的本机 Codex 连接器 |

固定扩展公钥用于保持扩展 ID 稳定，是公开标识，不是用户认证密钥。

## 备份、导出与删除

- JSON 备份包含标注、历史、回收站、草稿、配色与双语定位，带 SHA-256 完整性校验；校验不是加密。
- Markdown 导出包含勾选的现存标注与指定任务，不包含回收站、草稿及全部历史。
- 两种文件均为明文，请自行选择保存和分享位置。
- 找不到原文不会删除笔记；不确定的定位保留待处理。
- 整批撤销将该批自动标注移入回收站，保留最新笔记和历史。
- 卸载扩展或删除浏览器配置前，请先导出备份。

反馈问题请使用虚构示例或移除私人内容，不要附上连接令牌、私人备份或未授权分享的论文全文。
