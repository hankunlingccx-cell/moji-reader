这是本地保存的 Chrome 网页论文标注插件。默认仅在本地保存。使用 Codex 自动标注时，正文会交给 Codex 按你的要求分析。

开始标注

  1. 选中网页词句后，面板直接显示五种颜色，色块下方写有简短含义。点击颜色即可高亮，也可点击旁边的下划线、加粗或笔记图标。色块内不写文字。
  2. 点击已有标记，会在文字附近出现图标面板。面板优先放在文字上方并留出间距，顶部空间不足时放在下方，多行标记也会避让。点击下划线、高亮或加粗图标即可切换样式；点击笔记图标输入标签与笔记。垃圾桶图标用于删除标注，删除后可撤销或从回收站恢复。按钮会显示当前启用状态。
  3. 笔记和标签输入后自动保存为正式记录，无需点击保存按钮；界面显示“正在自动保存”或“已自动保存”。关闭面板或标签页，后台会继续处理已经发出的保存请求。标注库中的编辑也会自动保存。
  4. 鼠标悬停标记可查看标签与笔记。长按标记约 450 毫秒，会出现紧凑的横向色条。按住并移入颜色热区，色块放大，色块外仅显示颜色含义；此时松开即可换色，移出热区不会确认。也可长按松开后点击颜色，或用方向键和回车选择。

快捷键：Alt + Shift + H 高亮，U 下划线，B 加粗，N 笔记。均需先选中文字。Esc 取消换色菜单和重新定位。

自定义颜色与含义

点击选中文字面板中的齿轮，或在标注库展开“颜色与含义”。五种颜色均可自由选择，并填写 1–12 字的简短含义。点击“保存颜色设置”后，选色面板、侧栏和已有标记会同步更新。设置会在重启后保留，并随完整备份导出。导入时若与本机自定义设置冲突，会保留本机设置并提示。

统一的原文链接

标注库左侧只显示有标注的网页标题、标注数量和原文入口。点击网页标题后，右侧按原文顺序展示该网页下的全部标注、标签与笔记，顶部保留统一的原文链接。点击每条的“编辑笔记”会在该标注内展开编辑区，输入后自动保存；“历史版本”和“移入回收站”也在对应标注内操作。切换网页前已发送的保存请求会继续完成。网页阅读侧栏顶部也有“查看原文”入口。搜索框支持原文网址、网页标题、标注和笔记；旧标注会直接使用已保存的来源地址，无需重新标记。

一句话让 Codex 批注

连接桌面 Codex 后，打开目标论文，只需说“标注当前文章中影响团队创意的因素”，或“在这个网址标出研究方法”。默认规则已内置：先看章节目录，分页阅读去噪正文，按观点去重，用中文标签和短批注集中写入。可补充“只看讨论部分”或“最多 10 条”；没有限制范围时读完默认正文，参考文献按需读取。

段落和句子使用当前文章快照的编号，写入时由本地连接器还原原文，避免向模型反复传递长摘录。正文或翻译变化后旧编号会被拒绝，需要重新读取。节省多少取决于网页噪音、阅读范围和标注长度；目录与编号并不免除阅读相关证据。完成后可说“撤销刚才那一批”。

中英文双重定位

建议先打开英文原文，再开启谷歌中文翻译。插件记录翻译前后同一个正文段落的文本，中文标注和 Codex 批量标注都可保存双语定位。切换语言后先恢复精确摘录；只有段落对应时，整段显示标记并注明“跨语言段落定位”，不代表逐词对应。

如果首次打开页面时已经翻译完成，可显示一次原文再切回中文。无法自动建立对应时，点击侧栏记录的“绑定另一语言”，切换语言、选中对应句子，再点击“绑定此语言摘录”。原始摘录、标签和笔记会保留。双语信息可在编辑区查看，也包含在完整备份与 Markdown 导出中。翻译替换整段节点、重复文字或缺少对应依据时，记录保留待定位。

网页变化与重新定位

插件保存选中原文、前后各 80 字的上下文和位置。恢复时综合核对原文与上下文；只有两侧上下文都吻合、正文改动很小时，才尝试近似恢复。定位不确定时保留记录，侧栏提示“待重新定位”。页面延迟加载后会再次匹配。

手动定位：点击记录的“重新定位”，在页面上选中对应文字，再点击“将原记录定位到此处”。笔记、最初摘录和历史版本继续保留。网址中的跟踪参数与片段会忽略；其他查询参数保留。不同网址、镜像站点、不同版本论文不会自动合并。

导出给 AI（Markdown）

在标注库顶部点击“导出给 AI”。默认勾选当前网页，也可勾选其他网页，或展开网页逐条选择标注。网页复选框支持整篇选择和部分选中显示，另有“全选”和“清空”。右侧会实时预览准备下载的 Markdown；“给 AI 的任务”可以编辑或留空。

预览按文章分组，保留原文链接、摘录、当前自定义的颜色含义与色值、标签和你的批注，并附有标注编号和稳定 ID。没有批注或标签时会明确写出；重新定位前的最初摘录也会保留。摘录与批注分别放在文本块中，换行和代码不会丢失。

检查预览后点击“下载 Markdown (.md)”，将下载的文件提供给 AI。下载内容与预览一致。此功能导出已保存的选中内容，不包含回收站、历史版本和草稿；完整恢复备份仍使用“导出完整备份”。

保存与备份

标注与每次提交的完整版本保存在插件自己的 Chrome 本地存储中，写入并校验后才显示“已保存”。删除进入回收站，不会清空历史。标注库中可以恢复旧版本；网页侧栏的撤销重做用于当前页面会话。

多个窗口同时编辑同一标注时，自动保存会检测版本冲突并拒绝覆盖；冲突输入保留为独立草稿，可在标注库中找回。样式图标点击后立即保存，不需要额外确认。自动保存失败时会提示，请保留输入并继续编辑重试。

请定期导出备份。浏览器本地数据不能抵御卸载插件、删除浏览器配置、磁盘损坏或重装系统。标注库的“导出完整备份”包含标注、历史、回收站、草稿和颜色设置，并带 SHA-256 完整性校验。确认下载成功后，将文件另外保存。备份是明文 JSON，请妥善保管。导入只增加记录；同一 ID 内容冲突时保留独立副本，不覆盖已有内容。

支持范围

第一版支持 HTTP/HTTPS 普通 HTML 网页的主文档正文。需要允许插件访问相应网站，安装后请刷新已打开的网页。可以在插件详情页开启“允许访问文件网址”以标注本地 HTML。

Chrome 内置 PDF 阅读器、扫描图片、浏览器内部页面、Chrome 商店、iframe 内文档和网页组件的封闭 Shadow DOM 不在本版支持范围。在线论文请切换到 HTML / Full Text 正文。页面频繁重绘、禁止选中文字或特殊编辑器也可能影响显示；保存的记录仍可在标注库查看。

同步、云端备份和内置 PDF 阅读器尚未提供。打开同一网页的标记默认恢复并显示；“隐藏标记”仅对当前页面会话生效。
